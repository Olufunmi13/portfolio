# Funke Oluwatuyi — Portfolio

A responsive editorial-style frontend developer portfolio built with Next.js, React, TypeScript, and CSS.

## Run locally

1. Install Node.js (18.18+ recommended).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Project visuals

The `public/projects/` directory contains optimized WebP versions of the hero, full-page, and mobile screenshots supplied for these projects:

- Style Headquarters Atelier
- Innovate Health Africa
- ChessKindle
- Inkbooking Tattoo Studio
- Taxflow

The project cards use real hero screenshots with a mobile preview overlay. The `FULL PAGE` link opens the corresponding full-page screenshot, and the card links open each live website.
